|---|---|---|

ตำแหน่งสถานีฝั่งซ้ายและแนวเดินจากถนนกลางไปองค์พระยึดคำอธิบายผู้ใช้ร่วมกับภาพ ดู [MAP_LAYOUT.md](../../docs/design/MAP_LAYOUT.md)

ชื่อสถานที่ละเอียด ขนาดจริง ขอบเขตอาคารสถานี และรายละเอียดหน้าตาอาคารยังต้องแยกตรวจเพิ่มเติม ภาพนี้เป็นข้อมูลผัง ไม่ใช่ texture ที่ต้องแปะลงฉากโดยตรง
